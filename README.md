# BOS

A web-based mobile operating system interface built with HTML, CSS and JavaScript.

> **Project from 2024**

BOS was a personal project created in 2024 to experiment with recreating a mobile operating system experience directly in the browser.

## Features

* Lock screen with time and date
* PIN code interface
* Home screen with application icons
* Multiple application pages
* App opening and closing animations
* Calendar with different views
* Control Center
* Wi-Fi, Bluetooth, airplane mode and other controls
* Brightness and volume sliders
* Mobile-oriented interface
* Progressive Web App support

## Technologies

* HTML
* CSS
* JavaScript
* Progressive Web App APIs

## Running

No installation is required.

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/victorofsec/BOS.git
cd BOS
```

Then open `index.html`.

## About

This project was developed in **2024** as an experiment in front-end development and mobile interface design.

It is not intended to be a fully functional mobile operating system, but rather a browser-based recreation of the look and feel of one.

## Status

This is an archived personal project from 2024 and is no longer actively developed.
